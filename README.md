# pawsocks

плагин с уникальными фишками сервера [pawsocks](https://femden.zeroiq.club). paper 1.21.11, java 21.
для цены при наведении нужен плагин [packetevents](https://modrinth.com/plugin/packetevents) — без него всё остальное работает.

## фишки

| фишка | как пользоваться |
|---|---|
| **носки** | крафт из шерсти по форме ботинок: верхний ряд — цвет, нижний — полоска. в носках на 40% меньше урона от падения и быстрее копится уют |
| **уют** | шкала 0–100%: растёт у зажжённого костра, рядом со своим питомцем, когда сидишь или спишь, в носках. на 100% — лёгкая регенерация, пока тебя не бьют |
| **погладить** | шифт + пкм пустой рукой по кошке, собаке, лисе, кролику или попугаю: сердечки, звук, +уют |
| **обнимашки** | `/hug ник` → второй игрок жмёт [обнять] в чате → сердечки, мурчание, регенерация и уют обоим |
| **следы лапок** | за игроком остаются отпечатки лапок из частиц. цвет — в `/paw`. 4 цвета у всех, 4 можно купить в косметике, флаговые (радуга, трансфлаг, фембой-флаг) — с правом `pawsocks.trails.premium` |
| **переноска** | крафт: нить-кожа-нить / кожа-пусто-кожа / кожа ×3. пкм по своему питомцу — посадить внутрь, пкм по блоку — выпустить |
| **лапки 🐾** | своя валюта, ≈ доллар. `/bal`, `/pay ник сумма`, `/baltop`. счета в `data.db` (sqlite), все операции в журнале |
| **продажа серверу** | `/sell` (меню), `/sell hand`, `/sell all`. сервер покупает почти всё: цены из `prices.yml`, остальное считается по рецептам. чары и имя не учитываются, поломка снижает цену. `/sell all` не трогает инструменты, броню и вещи с чарами. чем больше вещи продали, тем дешевле она (насыщение рынка, остывает за 12 ч). не продаются: яйцо дракона, вещи за астры, шалкеры с вещами внутри |
| **цена при наведении** | в описании предмета видно, сколько даст сервер. только для глаз игрока, предметы не меняются; в творческом режиме выключено |
| **аукцион** | `/ah`, `/ah sell цена`. налог 5%, лот 48 ч, мои лоты, возврат непроданного, уведомление продавцу. яйцо дракона и вещи за астры выставить нельзя (и внутри шалкера тоже) |
| **магазин** | `/shop`: сервер продаёт блоки, растения, полезное и пластинки. цены в `shop.yml`, всегда минимум вдвое дороже скупки. лкм — 1, пкм — 16, шифт — стак |
| **доска заказов** | `/order`: «куплю 64 железа за 70 лапок». `/order create кол-во цена` с образцом в руке, деньги откладываются сразу. другие сдают вещи кликом и получают оплату (комиссия 3%), вещи приходят заказчику в возврат аукциона. до 3 заказов, 72 ч |
| **кузнец** | `/smith`: починка за лапки вместо опыта, сброс штрафа наковальни («слишком дорого!»), `/smith name текст` — имя предмету |
| **косметика** | в `/paw`: покупные следы (150), ауры над головой (250), символ после ника через luckperms (300). покупается навсегда |
| **дома** | `/sethome [имя]`, `/home [имя]`, `/delhome`, `/homes`. лимит по правам + докупленные точки (150 / 400 / 1000 / 2500), телепорт через 3 с |
| **астры ⭐** | вторая валюта: 1 за каждые 30 минут игры (до 5 в день, afk не считается) и 1–3 за ежедневный вход вместе с 5–15 лапками. день сменяется в полночь по москве. передавать нельзя |
| **магазин астр** | `/astra`: бур 3×3 на кирку (40), лесоруб на топор (25), автоплавка на кирку (20), магнит на инструмент (15), кошачье зрение на шлем (15), талисман «девять жизней» (30). чары работают в выживании, с шифтом бур и лесоруб выключаются |
| **меню `/paw`** | профиль (уют, обнимашки, время, лапки, астры), косметика, дома, следы, экономика, магазин астр |

## команды и права

| команда | право | по умолчанию |
|---|---|---|
| `/paw` (`/lapka`) | `pawsocks.menu` | все |
| `/hug ник`, `/hug accept`, `/hug deny` | `pawsocks.hug` | все |
| — следы лапок | `pawsocks.trails` | все |
| — особые цвета следов | `pawsocks.trails.premium` | оп |
| `/pawsocks reload` | `pawsocks.admin` | оп |
| `/bal [ник]`, `/baltop` | `pawsocks.balance` | все |
| `/pay ник сумма` | `pawsocks.pay` | все |
| `/eco give\|take\|set ник сумма`, `/eco info` | `pawsocks.eco.admin` | оп |
| `/sell`, `/sell hand`, `/sell all` | `pawsocks.sell` | все |
| `/ah`, `/ah sell цена` | `pawsocks.ah` | все |
| — лотов на аукционе больше 5 | `pawsocks.ah.listings.<n>` | — |
| `/sethome`, `/home`, `/delhome`, `/homes` | `pawsocks.homes` | все |
| — точек дома (по умолчанию 1) | `pawsocks.homes.<n>` | — |
| — без ограничений | `pawsocks.homes.unlimited` | оп |
| — телепорт без задержки | `pawsocks.homes.instant` | никому |
| `/shop` | `pawsocks.shop` | все |
| `/order`, `/order create кол-во цена` | `pawsocks.orders` | все |
| `/smith`, `/smith name текст` | `pawsocks.smith` | все |
| `/astra` (`/astry`, `/stars`) | `pawsocks.astra` | все |
| `/astra give\|take\|set ник число` | `pawsocks.astra.admin` | оп |

на сервере pawsocks выдано:

```
lp group active permission set pawsocks.homes.2 true
lp group supporter permission set pawsocks.homes.3 true
lp group supporter permission set pawsocks.trails.premium true
lp group moderator permission set pawsocks.homes.4 true
lp group owner permission set pawsocks.homes.unlimited true
```

## настройка

- `plugins/pawsocks/config.yml` — числа: сколько уюта даёт костёр, радиусы, кулдауны, множитель урона от падения. любую фишку можно выключить (`enabled: false`).
- `plugins/pawsocks/prices.yml` — цены скупки. чего там нет — считается по рецептам.
- `plugins/pawsocks/shop.yml` — что и почём продаёт `/shop`.
- `plugins/pawsocks/messages.yml` — все тексты, формат [minimessage](https://docs.advntr.dev/minimessage/format).
- после правки: `/pawsocks reload`.

уют, обнимашки, выбранные следы и настройки хранятся в данных игрока. счета, астры, журнал операций, лоты аукциона, возврат, заказы, покупки косметики и дома — в `plugins/pawsocks/data.db` (sqlite): её и стоит бэкапить.

## сборка

github actions собирает плагин при каждом пуше в `main` и выкладывает jar в [releases](../../releases). локально: `gradle build`, jar — в `build/libs/`.
